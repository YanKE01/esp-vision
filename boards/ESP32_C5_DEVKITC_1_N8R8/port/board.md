The following firmware is applicable to the ESP32-C5-DevKitC-1 development
board with an ESP32-C5 N8R8 module.

This bring-up profile enables the ESP32-C5 target, 8 MiB external SPI Flash,
8 MiB PSRAM, USB Serial/JTAG REPL, the ESP-VISION 8 MiB flash layout, Wi-Fi,
a generated fake camera backend for sensor and preview testing.
Native TinyUSB CDC/MSC is not enabled because ESP32-C5 does not provide a USB
OTG device peripheral.
